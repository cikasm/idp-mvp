# Internal Developer Platform (IDP) MVP

## Purpose

This repository documents the MVP development of a **plug-and-play Internal Developer Platform** aimed at DevOps teams, platform engineers, and engineering managers.

## Problem statement

DevOps teams struggle with existing IDPs due to complexity, high maintenance, and low adoption. We aim to create a lightweight, self-service IDP that automates common DevOps workflows.
